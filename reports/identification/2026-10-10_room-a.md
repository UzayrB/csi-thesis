## 6. The engine v5 ship plan, updated for the pick (written, not built)

**Engine v5 = v4 + A1, A3, A4, A5, M3** with the feature components weighted as below (the CNN weight 1); same CAL-causal pools and contract.

1. **A1 (dense offsets 0.05 to 0.50 s in training)**: training only: the dense offsets 0.05 to 0.50 s (`ilb_extract dense` and `ilc_extract`), appended as F7's; run time unchanged.
2. **A3 (time-stretched training windows, 0.9 and 1.1)**: training only: each training walk's frames rescaled in time by 0.9 and 1.1 (`ilb_extract stretch`, the engine's own `extract_window`), appended with pace v / s; run time unchanged.
3. **A4 (test-time average over 0, 0.15, 0.30 s)**: run time: the engine classifies three windows per press (0, 0.15 and 0.30 s after it) against the same CAL-causal pool and averages the ensembles; only the 0 s window enters the pool. The decision comes 0.30 s later and the CNN work triples; `Engine`/`Extractor` need a second and third poll per press.
4. **A5 (cross-day mixup)**: training only: one mixed row per training row (same person, same route, another day, weight U(0.2, 0.8), seed 0) in each component's normalised space; run time unchanged.
5. **M3 (gradient-boosted sixth component)**: training and run time: a sixth feature component (HistGradientBoosting on the Prior-standardised columns and pace) saved with the model; `Model` and `Session.classify` loop over six feature components.
6. **Weights (C2, room-aware), in practice one switch:** in Room A, with a model that trained in Room A, the feature components weigh 0.0 on path walks (the CNN components alone decide them); everywhere else (Room B, any new room, every identification walk) the weights are 1.0, as in the winner. **The room setting the app needs:** the installed room and whether the shipped model's training sessions include it, set once per installation before any press (no label from the test day). A new home always gets the unseen weight. The Room A weight was chosen on Room A's own test day (A3); confirming it needs a new Room A day.

**A4's timing:** three windows per press (0, 0.15 and 0.30 s after it), so the decision comes 0.30 s later and the CNN work per press triples; it is measured on the rig before adoption. Build order as the best-model report's section 7 (extractions, retraining, a version switch with v4 reproduced exactly when every change is off, every identification figure regenerated). Not built in this run.
