## 5. Pitfalls learned in this chat

- **`echo` of a grep count with `$` inside double quotes** can silently match nothing; check a known string first.
- **The macOS Bin cannot be read from the shell** ("Operation not permitted").
- **`fileproviderctl` has no `evict` on this macOS;** releasing Drive downloads needs Finder ("Remove Download").
- **Drive for desktop uploads nothing while paused;** an uploaded file gets the xattr `com.google.drivefs.item-id`.
- **`pd_repro_trace run` rewrites `verify/repro_trace/run/<cell>`:** rename the old folder first (`.pre_<event>`).
- **The chat window renders LaTeX `~` pairs as strikethrough;** give LaTeX to Uzayr in code blocks.
- **The auto-mode classifier blocked a bulk `rm` once;** moving to the Bin with Uzayr's explicit permission worked.
