## 1. The model: the live app, display K1g

**One model, and it is the live app** (Uzayr, 30 September).
- **What that means:** every tracking figure, render and rig run comes from `pipeline/live/`.
- **Offline code is a cross-check only:** `pipeline/constrained/pd_decode`, `pd_render`, `drawn_errors`.
- **The frozen configuration:** `runs/dc2_results/rule/FINAL_CONFIG.md`, hashed.

**What it is:**
- **The networks:** five heads, each one LinkCNN shared across the three links with a fusion head, trained on A1 +
  A2 + B1.
- **The inputs:** relative RSSI (minus the recording's idle mean).
- **The relative motion gate:** relgateU, band energy x max(1, G0 / g_rec) with G0 = 0.754.
- **The decode:** abstain in place of the veto, A2 start-term weight 0.25, the corrected readers.
- **The display:** **K1g**, look-ahead 1 window with the anchor gliding off the entry, since 1 Oct 00:02.

**The three modes:**
- **semi-constrained:** one start press per walk; **the headline**;
- **fully constrained:** start and end press; an upper bound;
- **unconstrained:** no press, m = 4; the weakest.

**Test sessions:** A3 (Room A, day 3) and B2 (Room B, day 2), never trained on. The zero-shot model is trained on
A1 + A2 only and tested on B2.

**The A3 label:** A3's lock and dot error are labelled OPTIMISTIC, because some display settings were chosen on
data that included A3 (`reports/DISPLAY_PROVENANCE_2026-09-30.md`). B2 is the headline.

## 8. The binding rules

- **Writing:** British spelling and no em dashes, everywhere.
- **Times:** run `date` before writing any time into a record.
- **Commits:** by name only, never `git add -A`; other sessions share the working tree.
- **What never to edit:** `data/`, existing reports and freezes. Write a new, dated file. (The freeze record is
  extended only by a dated addendum, as with `runs/TRACKING_FROZEN_2026-09-23h_ADDENDUM_C.json`.)
- **Briefs:** store each one verbatim (`reports/BRIEF_*.md`) with a `QUEUE.md` section, and work from the file,
  never from memory.
- **Processes:** kill by PID only, never broadly. Never touch Identification's processes, files or results.
- **Identification and machine time:**
  - talk to it directly (SendMessage "Identification");
  - for the GPU or a quiet machine, ask: it sets `runs/identify/audit/queue/HOLD_GPU` and replies "paused";
  - send "done" afterwards.
- **Long jobs:** run under `caffeinate -dimsu` with no timeout (Uzayr: keep the laptop awake while work runs).
- **The evidence standard:**
  - intervals on every figure;
  - edge lines beside every pooled figure;
  - figures from buggy code excluded, not corrected;
  - a component is signal-driven only if another participant's CSI changes its answer.
- **Records:** never overwrite a record; a new run goes to a new, tagged folder.

## 9. The lessons

1. **An untagged output folder will be overwritten by the next run.**
   - **What happened:** a default-display replay wrote K1g output into K0's folder, and a K1g stream would have
     overwritten K0's stream record.
   - **The fix:** both now tag every non-K0 display.
2. **Caches can write into hashed trees.** `recordings.gate_energy()` saves a cache into the cell's artefact folder
   when none exists, which would plant unlisted files beside the repro's inputs. Compute without saving.
3. **The causal clock moves windows by milliseconds.**
   - **The effect:** the app's g_rec differs from the tree's by up to 0.4 %, and a streamed run flips a few
     borderline locks.
   - **What to do:** take the app's own numbers from its replays.
4. **A brief's word can disagree with the data.** Room A's "idle before the first press" is not stillness (its
   band energy is near walking's). Report both, and say so.
5. **A failing test is not necessarily a figure problem.**
   - **What the 7 old failures were:** stale registries and a stale README check.
   - **What to do anyway:** read each site in context before classifying it.
6. **Logging slips:** `$?` read after `$(date)` reports the date's exit code, which happened once today (Monitor's).
   Capture the code first.
7. **Guessed times end up in records.** Read the clock.
8. **Do not announce work that has not been launched.** It has cost this project hours.
9. **Leakage enters through aliased frozen heads.** Audit decodes by tracing the files they open (the reader leak,
   29 Sep).
